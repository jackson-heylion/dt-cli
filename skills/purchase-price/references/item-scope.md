# 品项范围

先确定范围和候选，再查价；价格是否为空不能反向改变品项定义。

| 意图 | 范围 |
| --- | --- |
| 完整编码／具体商品 | 核对完整编码、名称和规格，可靠同系统 ID 可复用 |
| 名称包含某词 | 按字面检索，符合字面条件的制品也属于候选 |
| 猪肉、牛肉、鸡肉、虾等食材大类 | 默认原料及常规分切，鲜冻均可；成型、熟食、罐头、调味料另归类 |
| 明确包含相关制品 | 用户范围优先，保留类别 |

默认范围可直接执行，一句话说明。肉馅是否调味、部位所属畜种或邻近类别无依据时列待核实；实质跨类歧义集中确认。

## 候选检索

有同系统分类目录且接口支持时优先使用，核对子类覆盖。当前最低清单只有名称／编码搜索，不借预估系统类目 ID，也不自动下载全量主数据。

名称检索先选核心词，必要时补少量部位／别名，通常不超过3词；已有结果也可补有据线索，但不因价格少扩词或纳入制品。名称命中不能证明类别完整。

候选用契约允许的合适页长，当前 STG 可用100；展示5条价格不等于只读5个候选。按任务预算读取必要页，按同域 ID 合并去重，再根据真实名称、规格、类目分为纳入／排除／待核实。

冷冻、产地、规格、去骨／带骨和切条／切块不是额外排除条件；“加工牛肉类”可能只是分切，不能只看类目中的加工二字。单字“牛”也会命中牛奶、牛蛙等，须核对真实类别。

## 离线分类工具

默认牛肉、猪肉、鸡肉、原虾／虾仁范围可复用工具，避免重写分类正则。其他食材、名称包含或明确含制品时按用户范围判断，不硬套原料规则。

```sh
python3 <采购价目录>/scripts/classify_items.py --family 牛肉 --input <第1页正文.json> --input <第2页正文.json> --output <新分类结果.json>
```

输入为含 list 的业务正文或品项数组。工具保留真实 id、code、name、specification、itemCategoryName；同 ID 来源冲突、名称类目矛盾或原味／调理等不明形态列待核实。只需读取摘要和边界项，完整候选留文件。

有本次真实证据时可传 review-file，decisions 每项含 id、decision（纳入／排除／待核实）、reason、source；无证据保持待核实，无需追加探测核对所有边界项。

输出 included、pending、excluded 互斥且覆盖唯一 ID；查价只用与 included 完全一致的 itemIds，不再手工合并待核实项。工具不证明整类穷尽。

## 固定查价集合

非空纳入集合按单次上限批量查询，各批使用相同日期、范围、状态与排序；后续确有新增同类候选只查 ID 差集。零候选停止，制品价格不能替代原料结果。

授权的“全部可查范围”与类别穷尽分开。仅名称检索或部分读取时说明“本次检索范围”，不能称全部同类只有这些价格。
