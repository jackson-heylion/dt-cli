# 采购价查询

读取已安装的 `dt-cli`（至少0.7.5），通用执行依其规则；接口和日期映射见[查询步骤](references/query.md)。

1. 默认查本人全部可查范围，不沿用上一轮配送中心；普通采购价默认当前有效，“最近”按更新时间倒序，不附加时间窗口。本次明确限定配送中心时才收窄。
2. 按[品项范围](references/item-scope.md)区分具体商品、名称包含和食材类别。先合并去重、分类，再用非空真实 ID 集合批量查价；超过契约上限才分批。
3. 核对返回品项、客户类型、失效标志与有效期，按实际覆盖交付。结果不足按实际数量结束，不扩大条件凑数。

价格表展示品项、规格、供应商、适用门店／仓库、单位、未税价、含税价和有效期；不同规格、单位及适用对象分别保留。表后只写查询日、有效口径和必要覆盖限制。
