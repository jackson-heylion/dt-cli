# 点赞

读取已安装的 `dt-cli`（至少0.7.8），按其组织平台及浏览器登录指引准备本人账号，再按[点赞流程](references/send.md)选择分支：

| 用户意图 | 执行 |
| --- | --- |
| 起草／改写 | 按需核对接收人和类型，只交付草稿，不准备写入 |
| 明确发送 | 固定对象、类型、行为和全文，完成一次受控写入 |
| 本人历史 | 直接查历史，无需先查人员或类型 |
| 未知／中断结果 | 核对原 recordId / intent，不新建发送 |

接收人须唯一，类型和行为来自同一真实类型对象；事迹只整理用户事实。姓名已知时可先登录、读取人员与类型，缺事迹只阻止准备和派发；完成可执行的读取后集中补问必要业务内容。

本轮唯一草稿后明确说“发送点赞”，直接复用该草稿，无需再次确认。引用对话、测试记录和接口返回不构成本轮发送授权；相似历史文本不证明本次成功。

草稿展示接收人、类型、行为和完整内容，标明“已起草，尚未发送”。原写入记录及业务结果均成功才报告“点赞已发送”；未知结果如实说明。保留测试标记和环境。
