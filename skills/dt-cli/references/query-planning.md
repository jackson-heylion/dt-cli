# 查询规划

业务 Skill 决定接口和业务含义；这里只处理会改变结果的范围、衔接和覆盖。简单查询直接执行，无需向用户展示技术计划。

## 参数与候选

- 复用已确认的本人、环境、对象和可靠同系统 ID。目标接口支持名称时直接查；只接受 ID 时先搜索。关联使用真实上游结果，区分显示编码、数据库 ID 和 AUTH 对象 ID。
- 按当前契约核对位置、类型、单位、默认、联动、排序与分页；业务语义以业务参考为准。冲突时停止受影响分支，不猜字段试传。
- 原词优先，完整编码保留前导零；相似名称不等于精确匹配。类别与名称包含分别处理，企业分类或有据别名优先，AI 扩词仅作补充线索。
- 候选按同域稳定 ID 去重。明确类别可批量处理，实质歧义集中消歧；空结果只说明本次条件未命中，不自动改对象或扩大到其他门店、年份。
- 筛选尽量交服务端；接口不支持时，只在原范围内有界后筛，并记录额外读取。授权与对象边界仍由服务端保障。

## 时间与状态

固定本次查询日／时刻和业务时区，跨页复用。用户明确口径优先，其次采用业务 Skill 默认；“最近”“有效”没有已确认含义时补问。

字段格式与单位遵循契约，创建、更新、生效和到货时间分别映射。同一字段的范围先合并；无交集则不发送请求，JSON 参数名保持唯一。

当前状态不能证明历史执行或未来适用性；缺历史快照时只交付能证明的候选和证据缺项。

## 数量、分批与排序

| 用户表达 | 执行含义 |
| --- | --- |
| 先查／看看／展示前N条 | 最多展示N条；可为同一筛选有界读取候选和多批结果 |
| 实际只读／最多拉取N条 | 目标记录跨页、对象和批次共享严格总预算；对象候选另记 |
| 最新／最低价前N条 | 需要可比维度、正确排序和全部目标批次覆盖 |
| 全部／共有多少 | 需要完整候选和分页结束证据；未完成则交付部分 |

超过单次 ID 上限才分批，批次不重叠；新增候选只补查差集。结果不足N条按实际交付，不为凑数追加其他日期、状态或对象。

多批 Top N 只有各批排序一致、各自取得足够候选且批次全部覆盖后才能合并；不支持的排序需完整读取后处理。严格读取预算不足以证明全局排名时，说明冲突并集中确认范围或预算。

单次 call 的 pageSize 与工作包默认页长分别核对；展示数量不等于读取数量。分页恢复保留原 jobId，不新建工作包绕过限额。

## 结果核对

核对真实对象、范围、状态和日期；返回违背条件时停止该口径输出。内部记录已读页、命中／去重／后筛数量、未读范围和停止原因；接口 total 不等于后筛总数。

候选、各批、分页和日期覆盖均完成才能称全部。缺页、重复、并发变化和缺字段单列；分时读取不承诺快照。面向用户只保留影响结论的限制。
